# Project 1 — Website NusantaraTrip

Website PHP Native untuk company profile dan informasi paket wisata. Aplikasi menggunakan database bersama yang berada di folder `database/` pada repository utama. Import SQL tersebut terlebih dahulu, lalu buka `index.php` melalui Apache.

Daftar akun dapat dibuat dari halaman **Daftar**. Login menggunakan email atau username dan kata sandi yang dipilih saat registrasi.
